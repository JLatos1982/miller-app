# Finance / Public Money Branch Maturity — Dossier Pilot

| Capability | Maturity | Dossier evidence | Limit |
|---|---|---|---|
| Program funding extraction | working | Road to Recovery and In Plain Sight program amounts retain program scope | Announcements do not provide service allocations |
| Recipient identification | working | New Roads and both FNHO contribution records name recipients | A named recipient does not establish detailed expenditure |
| Amount normalization | working | CAD amounts remain numeric with source date and attribution note | Fiscal periods and recurring status still require source-specific interpretation |
| Service-level attribution | working_with_limits | New Roads reaches named service level | Creekside correctly stops at program level |
| Funding-to-service verification | working | New Roads and Creekside connect to current operational evidence | Operation is not effectiveness or audited use of funds |
| Audit/follow-up | prototype | Annual reports and proactive disclosure add later context | No dossier establishes a full audited program-to-service expenditure chain |

The Finance branch is ready for private, conservative traceability when the source explicitly names amount, recipient or service. It is not an accounting system and should not allocate broad envelopes algorithmically.

Recommended next validation: add one fixture whose chain intentionally stops at `program_level`, and one with an authoritative service-level audited statement, if such a source becomes available.
