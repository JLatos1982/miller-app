Each fixture has a stable private ID, domain, source set, evidence-edge references, relationship types, confidence, unresolved questions, owner-review notes, significance class and validation rationale in the structured JSON.

The fixture set is intentionally plural: no single example tests policy-to-resource identity, direct service funding, Indigenous governance and incomplete accountability reporting safely.
