# Miller North feedback and correction pathway — private handling plan

## Public entry point

The methodology page explains four future request types:

- factual or source-link error
- relevant public-source suggestion
- updated public implementation evidence
- correction or removal review

The page explicitly asks readers not to submit confidential medical records or private personal information. No browser form is active in this pass.

## Minimum future submission fields

- request type
- public page URL
- public source URL, if applicable
- concise explanation of the possible error or update
- requested correction or review outcome
- optional reply address, stored separately and never published

## Excluded content

- medical records or clinical files
- identity clues concerning an anonymized person
- private addresses, phone numbers, or third-party email addresses
- allegations about a named worker without an authoritative public source
- credentials or internal documents

## Private handling

1. Validate URLs and reject attachments.
2. Store the request privately with an owner-review gate.
3. Reproduce the issue using public sources.
4. Record a non-destructive correction proposal.
5. Require explicit approval before changing any public projection.
6. Keep contact information out of evidence records and publication artifacts.

## Launch dependency

Choose and privacy-review the actual intake destination before enabling the public control. Until then, the page accurately states that no browser form collects information.
